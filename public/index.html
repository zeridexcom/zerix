API Playground & Automation Webhooks

Integrate Review Automator into n8n, Zapier, CRMs, or custom code

POST /api/request (WhatsApp)

Trigger a review request via WhatsApp.

curl -X POST http://localhost:3001/api/request \
  -H "Content-Type: application/json" \
  -d '{
    "customerName": "Jane Smith",
    "phone": "+447700900000",
    "channel": "whatsapp",
    "jobReference": "JOB-1029"
  }'
POST /api/request (Email)

Trigger a review request via Email.

curl -X POST http://localhost:3001/api/request \
  -H "Content-Type: application/json" \
  -d '{
    "customerName": "Jane Smith",
    "email": "jane@example.com",
    "channel": "email",
    "jobReference": "JOB-1029"
  }'
GET /api/requests

Fetch all review requests sorted chronologically.

curl http://localhost:3001/api/requests
POST /api/follow-up

Trigger follow-up reminder cycle for customers due past the threshold.

curl -X POST http://localhost:3001/api/follow-up

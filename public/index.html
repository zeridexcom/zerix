Good News: The App Is 100% Functional!

When OpenWA is offline, the app automatically runs in Direct WhatsApp mode. Every review request generates a 1-click wa.me link with the complete pre-filled review invitation. You can dispatch messages directly from your personal or business WhatsApp with zero interruption!

help Why It Is Not Working (Root Cause)
  • Port 2886 Unreachable: The backend tried to ping http://localhost:2886/api/sessions and received Connection Refused (fetch failed).
  • Docker WSL2 Platform on Windows: OpenWA runs as a Linux container in Docker. On Windows machines, if WSL2's VirtualMachinePlatform feature is not enabled, the Linux engine cannot start.
  • Container Stopped: The container zerix_gateway is not running or hasn't been launched yet.
build How Admin Can Fix It

Option 1 (Start Docker Gateway):

wsl --install --no-distribution; docker compose up -d zerix_gateway

Then visit http://localhost:2886 and scan the QR code with WhatsApp.

Option 2 (Zero Setup): Stay in Direct WhatsApp mode. No Docker or container needed!
